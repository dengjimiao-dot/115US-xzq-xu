标识：实际作为当前克隆外观来源的普通装扮，在格子右上角显示绿色人形；按物品实例及实际背包位置匹配，不按模板号匹配同款物品。每次绘制读取当前来源关系，不保存额外状态。素材为原生 `sprite_item.NPK → sprite/item/iconmark.img → 403`（从 0 计数），与用户提供的官方参考图不透明图案像素一致，国服与 US 这一帧的 RGBA 像素完全一致。既有资源无须替换。

真源：DFO.exe SHA256 `6c78cdf8c1db4426c2438c609601416a34cf9a9f0baeda23e49f9c9499dd7a43`。源判定对应 1469E3090 的 Find/Part/Source，普通物品绘制虚表槽 +2A0（原生 145A662D0）；来源对象复查 manager+A8[slot] 节点 -40 的实际指针。绘制参数为 RCX=item，XMM1/XMM2=x/y，R9=options。原生绘图上下文为 item+18。145006577 的调用确认 146EBBD30 的八参数 ABI；14572F600/14572F62B 确认资源管理器 `base+F1C39C8`、取包虚函数 +10、取帧虚函数 +78 与原生 intrusive 引用释放。只在绘制线程按需取现有资源；每次绘制后成对释放引用，不保存裸指针、不在 DLL 初始化时加载素材。

第 403 帧为 28×28 画布中的 11×13 图案，原始偏移 (17,15)。绘制时 Y 减去 15，让图案出现在右上角；缩放和裁剪沿用该物品的原生上下文。实际 UI 位置和切换行为仍待用户实机验收。

只在所有函数、资源调用点及虚表期望字节一致时挂钩；读取异常或原生状态异常时跳过/禁用角标。资源虚函数必须位于当前主模块的可执行内存中。原生物品绘制仍先执行。日志是 DLL 同目录的 `115-shop-tabs.log`，搜 `AVATAR_MARKER`，新版本日志包含 `frame=403`。

基于本机已安装的 player-pet-mono-v4 来源，现有商店、中文字体和其他插件代码保持原样。本包整体替换唯一 dinput8 槽位，不新增第二自动加载 DLL，不是需要额外宿主的并行插件。构建物全部位于 dist，schema 2 mod 支持备份和逐字节卸载恢复。
